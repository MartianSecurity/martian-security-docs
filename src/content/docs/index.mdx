## Start with your workspace

Explore the [Local SDK guides](/local-sdk/) for evaluations, the local UI, and importing results. The [Community quickstart](/get-started/quickstart/) runs without a Martian account or model key. [Editions](/get-started/editions/) explains which workflows need a shared workspace.

The SDK guides cover [Martian SDK 0.3.1](/sdk/install-and-configure/#sdk-031-at-a-glance), including [pull-request checks with job summaries](/sdk/ci/#run-a-local-suite-on-pull-requests) and [portable Evals exports](/sdk/local-ui/#export-and-restore-evals-records).

New to Martian? [Accept your invitation and sign in](/get-started/access/), then read [the concepts](/get-started/concepts/). You need an agent connection that you are authorized to test. Each tutorial explains the role, setup and limits before you start.

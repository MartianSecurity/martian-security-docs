## Install the Local SDK

Use Python 3.12 or newer. Follow [Install with pip](/sdk/local-installation/#install-with-pip) or [Install with uv](/sdk/local-installation/#install-with-uv) from your project directory.

## Open the preview workbench

For the preview guides, install a candidate wheel in an isolated environment. Replace `PREVIEW_WHEEL.whl` with the supplied wheel's filename. For MCP, use `[evals,mcp]` in the install command. [SDK implementation PR](https://github.com/MartianSecurity/martian-redteam/pull/318)

Use a new data folder for the preview. To try it with existing runs, stop every process writing to your current data folder, copy the entire folder, and open the copy in the preview. The candidate can upgrade the local database schema.

```sh
python -m pip install '/path/to/PREVIEW_WHEEL.whl[evals]'
martian ui --data-dir ./evals-data --ui-dir /path/to/workbench
```

Point `--ui-dir` at the matching workbench build's folder containing `index.html` and `assets/`. With a candidate wheel that already bundles that workbench, start it with `martian ui --data-dir ./evals-data`. The workbench footer shows the build revision.

## Import existing results

Bring runs into the local UI from [MLflow](/migrate/mlflow/), [Promptfoo or Marsfoo](/migrate/promptfoo/), or [Inspect AI](/migrate/inspect/).

To record results in a shared workspace, see [Configure the SDK for a workspace](/sdk/install-and-configure/).

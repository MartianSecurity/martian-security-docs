## Install the Local SDK

Use Python 3.12 or newer. From your project folder in Bash or Zsh, create a virtual environment and activate it.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade 'martian-sdk[evals]'
martian --version
```

In each new terminal, run `source .venv/bin/activate` from the same folder before using `martian`. The [SDK version guide](/sdk/install-and-configure/#sdk-versions-and-workflows) lists the Python package and container releases separately.

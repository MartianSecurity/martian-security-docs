Run evaluations and inspect saved results on your machine with the Martian SDK. The Community quickstart uses deterministic checks and needs no Martian account or model key.

## New in SDK 0.4.0

- **Findings.** Review evidence across saved scans, record triage, and export CSV, SARIF, or NeMo Guardrails bundles. [Review and triage local findings](/sdk/local-findings/)
- **Remediation Reports.** Open a prioritized plan, print it or download a PDF, draft a prompt change, and record a verified fix after a follow-up scan with matching coverage. The CLI can also write standalone HTML. [Read and verify remediation reports](/sdk/local-remediation/)
- **Promptfoo and Marsfoo migration.** Preview supported config conversion, import saved verdicts, traces and media, and compare the imported runs against native runs with compatible grading rules. Reimporting unchanged archives preserves their reviews. [Migrate from Promptfoo or Marsfoo](/migrate/promptfoo/#migrate-with-the-current-sdk)
- **Deterministic checks.** Validate XML and embedded JSON, measure word count and edit distance, and use weighted checks in a suite. [Evals suite YAML](/sdk/local-evals-yaml/#deterministic-checks)
- **Local MCP.** Read saved run records and reports through a local stdio client. Use preview mode to validate a suite or run a deterministic check on supplied data. [Connect to the local SDK over MCP](/sdk/local-mcp/)
- **Workbench tables.** Column dividers run through the headers and rows of the bundled UI. [See the Runs table](/sdk/local-ui/#runs)

## Install the Local SDK

Use Python 3.12 or newer. Follow [Install with pip](/sdk/local-installation/#install-with-pip) or [Install with uv](/sdk/local-installation/#install-with-uv) from your project directory.

## Open the bundled workbench

Install or upgrade to SDK 0.4.0 or later to use local Findings and Remediation Reports. Install both the `evals` and `mcp` extras if you plan to [connect an MCP client](/sdk/local-mcp/).

```sh
python -m pip install --upgrade 'martian-sdk[evals]'
martian ui --data-dir ./evals-data
```

The SDK can upgrade a local database when it opens the data folder. Before upgrading an existing store, stop the processes writing to it and copy the entire folder. Open the copy to confirm your saved runs and reviews. The workbench footer shows the bundled UI revision.

## Import existing results

Bring runs into the local UI from [MLflow](/migrate/mlflow/), [Promptfoo or Marsfoo](/migrate/promptfoo/), or [Inspect AI](/migrate/inspect/).

To record results in a shared workspace, see [Configure the SDK for a workspace](/sdk/install-and-configure/).

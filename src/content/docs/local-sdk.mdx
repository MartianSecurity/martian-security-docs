Run evaluations and inspect saved results on your machine with the Martian SDK. The Community quickstart uses deterministic checks and needs no Martian account or model key.

| I want to | Start here |
| --- | --- |
| Install the SDK and try two example runs | [Community quickstart](/get-started/quickstart/) |
| Evaluate a Python function or HTTP target with a YAML suite | [Run evals locally with a suite file](/sdk/local-evals/) |
| Write checks in Python and run them with pytest | [Free local Python preview](/sdk/evaluations/#1-run-the-free-local-preview) |
| Open, compare, export, or restore runs | [Use the local Evals UI](/sdk/local-ui/) |
| Find saved local Red Team reports | [Read the report in the local UI](/sdk/redteam-local/#5-read-the-report-in-the-ui) |
| Check a pull request with a deterministic suite | [Run a local suite in GitHub Actions](/sdk/ci/#run-a-local-suite-on-pull-requests) |

## Import existing results

Bring runs into the local UI from [MLflow](/migrate/mlflow/), [promptfoo](/migrate/promptfoo/), or [Inspect AI](/migrate/inspect/).

To connect the same SDK to a shared workspace and record CI sessions, see [Install and configure the SDK](/sdk/install-and-configure/).

## At a glance

| Edition | Availability | How to start |
| --- | --- | --- |
| **Community** | **Available**. Open-source SDK and local UI for one user. | [Run the Community quickstart](/get-started/quickstart/). No account is needed. |
| **Enterprise** | **Invite-only beta**. Martian hosts the console and shared workspace. | [Request a workspace](/get-started/access/). |
| **On-Premises** | **Upcoming**. The console is planned for deployment in your infrastructure. | [Discuss your requirements](mailto:founders@martiansecurity.ai). |

**Available** means released for use. **Invite-only beta** means access through a hosted workspace, subject to its roles and configuration. **Upcoming** means there is no public release. A dash means the edition does not include the feature.

Community is published as [`martian-sdk` on PyPI](https://pypi.org/project/martian-sdk/) under the [Apache 2.0 license](https://github.com/MartianSecurity/martian-redteam). Enterprise users can install the same SDK for local work. The [SDK version guide](/sdk/install-and-configure/#sdk-versions-and-workflows) lists the Python and Docker releases.

### Export and share evidence

- **Community · Available.** Export CSV and JSON from the UI or [export and restore the local Evals store](/sdk/local-ui/#export-and-restore-evals-records). The command line also produces JSONL, summary JSON and JUnit reports.
- **Enterprise · Invite-only beta.** Share results in your workspace or export from [evaluation runs](/evals/results-and-scores/) and [assessment history](/assessments/history-and-exports/).
- **Enterprise · Upcoming.** Formal evidence packs and sign-off records.

## What separates the editions

| | Community | Enterprise |
| --- | --- | --- |
| Sign-in | One user with no login | Workspace members sign in with assigned roles |
| Data | Local results in a folder you manage. Targets and judges can use services you configure. | Shared results in the hosted workspace |
| Access to team features | Individual runs and annotations | Shared projects, assigned reviews, monitoring, and CI sessions |

To run the local UI on a server, use the [Community Docker image](/sdk/local-ui/#6-run-the-ui-in-a-container) for one user and keep it private.

### Limits

The local UI defaults to one evaluation and one scoring job at a time. Set [`martian ui --concurrency`](/sdk/local-ui/#1-install-and-start-the-ui) to choose a different allowance. In a shared workspace, check the [workspace limits](/reference/limits/).
